# Digital Ustad™

> **Build • Grow • Automate**  
> Complete digital solutions, web development, ROI-driven marketing, and business automation.

## 🚀 Live Website
Deployed on Netlify.

## 📂 Project Structure
- `index.html`: Modern Bento-grid homepage with aurora lighting and micro-animations
- `services.html`: Master services hub
- `service-*.html`: 6 dedicated service detail pages
- `solutions.html`: Industry-specific solutions (restaurants, clinics, salons, real estate, etc.)
- `portfolio.html`: Filterable project showcase modal
- `about.html`: Agency values and credentials
- `contact.html`: Interactive quotation calculator and direct WhatsApp proposal generator
- `assets/images/`: Official brand logos (`logo-dark.png`, `logo-light.png`, `favicon.png`, etc.)
- `css/`: Custom Tailwind CSS animations and glassmorphism styling
- `js/`: Accordion, portfolio modal, scroll progress, and mobile drawer logic
- `netlify.toml` & `_redirects`: Netlify deployment configuration & routing
